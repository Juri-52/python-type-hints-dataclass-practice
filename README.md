# 第09回 自主課題：型ヒントとデータクラス

文房具ショップを題材に、型ヒントで関数の使い方を明確にし、dataclassで商品を表現します。最後に、カタログから検索した商品をカートへ追加します。

## 進め方

| 順番 | フォルダー | 学習すること |
| --- | --- | --- |
| 1 | [01_type_hints](01_type_hints/README.md) | 引数・戻り値・リストの型 |
| 2 | [02_dataclass](02_dataclass/README.md) | フィールド・デフォルト値・比較 |
| 3 | [03_catalog_cart](03_catalog_cart/README.md) | クラス間の連携・検索・Noneの確認 |

各フォルダーのREADMEを読み、順番に完成させてください。配布コードは最小限のひな形です。`pass`のままでは、課題の処理は行われません。型ヒントも自分で追加します。

## 共通ルール

- 引数と戻り値に型を書きます。`self`自身の型を書く必要はありません。
- 戻り値が不要な関数には `-> None` を付けます。
- 表示が必要な処理はmain.pyに書き、計算や検索のメソッドは結果を返します。
- 第3課題は配布済みの10商品を使います。
- 実装するのは指定された内容だけです。発展課題はありません。

## 提出

3つのフォルダーの完成したPythonファイルとREADMEを、指定されたGitHubリポジトリに提出します。配布データも残してください。3つのmain.pyを実行し、各READMEの確認項目を満たしてから提出します。
