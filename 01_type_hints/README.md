# 課題1：価格を扱う関数に型を付けよう

ショップの商品価格を計算・表示するための小さな関数を作ります。main.pyから呼び出し、引数と戻り値の型が読み取れるコードにします。

## 作るもの

functions.pyの関数を完成させ、すべての引数と戻り値に型ヒントを書いてください。

| 関数 | 引数の内容と型 | 戻り値の内容と型 |
| --- | --- | --- |
| calculate_total(price, quantity) | 単価と個数：どちらもint | 単価×個数：int |
| make_label(name, price) | 商品名：str、価格：int | 「商品名: 価格円」の文字列：str |
| sum_prices(prices) | 価格のリスト：list[int] | すべての価格の合計：int |

今回は単価と個数に0以上の整数が渡されるものとします。空の価格リストの合計は0です。関数の中で表示するのではなく、計算結果や文字列をreturnで返してください。

## main.pyで確認すること

functions.pyから関数をインポートし、次の順番で結果を表示します。

1. 単価200、個数3の合計。
2. 商品名「ノート」、価格200のラベル。
3. 価格リスト [200, 150, 100] の合計。
4. 空のリストの合計。

期待する表示：

```text
600
ノート: 200円
450
0
```

## 型チェックの確認

完成後、calculate_totalを呼ぶ箇所の200を、一時的に文字列の"200"へ変えます。IDEの警告を確認し、実行すると文字列が繰り返される理由を考えます。確認後は整数200に戻して提出してください。

## 実行

このフォルダーで `python3 main.py` を実行します。

## 完了条件

- 3つの関数に引数と戻り値の型がある。
- 関数が結果を返し、main.pyが表示する。
- 空のリストを含め、上の4行と同じ結果になる。
