# 課題2：商品をdataclassで表そう

商品の番号・名前・価格を、1つのオブジェクトにまとめます。自動生成される初期化・表示・比較の動作を確認し、商品を表示する独自のメソッドも作ります。

## Productの仕様

product.pyのProductに、必要なインポートとデコレーターを追加してdataclassにしてください。手動の__init__は書きません。

| フィールド | 型 | 初期値 |
| --- | --- | --- |
| product_id | int | 必須 |
| name | str | 必須 |
| price | int | 0 |

get_info()は、次の形式の文字列を返します。戻り値の型も書いてください。

```text
1. ノート - 200円
```

今回は、商品の番号は正の整数、価格は0以上の整数、名前は空ではない文字列とします。入力処理や値の検査は不要です。

## main.pyで確認すること

次の3つのオブジェクトを作ります。

- notebook1：商品番号1、名前「ノート」、価格200。
- notebook2：notebook1と同じ値で、別に作成したオブジェクト。
- sample：商品番号11、名前「試供品」。価格の引数は省略。

次の順で表示してください。

1. notebook1のget_info()の結果。
2. notebook1そのもの。
3. sampleのprice。
4. notebook1とnotebook2を == で比較した結果。
5. notebook1とnotebook2を is で比較した結果。

期待する表示：

```text
1. ノート - 200円
Product(product_id=1, name='ノート', price=200)
0
True
False
```

==とisの結果が違う理由を、main.pyの普通のコメント（#）で1〜2文説明してください。

## 実行

このフォルダーで `python3 main.py` を実行します。

## 完了条件

- Productがdataclassで、3つのフィールドに型がある。
- 価格を省略すると0になる。
- get_info()は文字列を返す。
- 初期化・表示・比較の標準メソッドを自分で書かずに、指定の結果を確認できる。
