# 課題3：検索した商品をカートに渡そう

ショップのカタログから商品番号で商品を検索し、見つかった商品を買い物かごへ追加します。見つからない場合はNoneを返すことで、「商品がある場合」と「ない場合」を区別します。

メニューを作る課題ではありません。main.pyに決まった操作を書き、複数のオブジェクトの連携を確認します。

## 準備とファイルの役割

1. 第2課題で完成したproduct.pyの内容を、このフォルダーのproduct.pyにコピーします。
2. catalog.pyのCatalogを完成させます。
3. cart.pyのCartを完成させます。
4. main.pyに確認用の処理を書きます。

| ファイル | 役割 |
| --- | --- |
| product.py | 第2課題のProductを再利用 |
| sample_data.py | 配布済みの10商品の辞書リスト。変更しない |
| catalog.py | 商品オブジェクトの一覧と検索 |
| cart.py | 検索した商品を追加し、合計を計算 |
| main.py | 辞書からProductを作り、各クラスを使って確認 |

sample_data.pyのPRODUCTSは辞書のリストです。各辞書のproduct_id、name、priceを使い、main.pyでProductのオブジェクトのリストを作ってください。そのリストをCatalogへ渡します。以前の買い物かごと同じ10商品を使います。

## Catalogの仕様

Catalogは通常のクラスです。

| 要素 | 仕様 |
| --- | --- |
| __init__(products) | Productのリストを受け取り、self.productsに保存する |
| self.products | list[Product] |
| find_product(product_id) | intの商品番号を受け取り、該当するProductを返す |
| 見つからない場合 | Noneを返す |

find_productの戻り値には、ProductとNoneの両方の可能性を書いてください。見つかった場合は、カタログに入っているオブジェクトをそのまま返します。

## Cartの仕様

Cartも通常のクラスです。

| 要素 | 仕様 |
| --- | --- |
| __init__() | 自分専用の空のリストself.itemsを作る |
| self.items | list[Product] |
| add_product(product) | Productを受け取り、self.itemsに追加する。戻り値は不要 |
| get_total() | カート内のpriceの合計をintで返す。空なら0 |

同じ商品を2回追加したら、リストの2要素として扱います。商品名や商品番号だけでなく、Productのオブジェクトを保存してください。合計の表示だけでなく、実際に追加されていることが必要です。

各メソッドの引数と戻り値に型を書きます。__init__の戻り値はNoneです。

## main.pyで行う操作

1. 配布データをProductのリストに変換し、Catalogを作ります。商品の数を表示します。
2. 空のCartを作ります。
3. 商品番号1を検索します。Noneでないことを確認し、get_info()を表示して同じ商品を2回カートに追加します。
4. 商品番号2を検索します。Noneでないことを確認し、カートへ1回追加します。
5. 商品数と合計を表示します。
6. 商品番号999を検索します。見つからない場合は「商品が見つかりません」と表示し、カートには追加しません。
7. 合計をもう一度表示し、変わっていないことを確認します。
8. 別の新しいCartを作り、その合計を表示します。

期待する表示：

```text
商品数: 10
1. ノート - 200円
カート: 3点
合計: 550円
商品が見つかりません
合計: 550円
新しいカート: 0円
```

ProductまたはNoneという結果を、確認せずにadd_productへ渡さないでください。型ヒント自体はNoneの追加を実行時に禁止しません。

## 実行

このフォルダーで `python3 main.py` を実行します。

## 完了条件

- 第2課題のProductを再利用している。
- CatalogとCartのリストの中身がProductになっている。
- 検索結果の型がProductまたはNoneになっている。
- 見つからない商品をカートに追加しない。
- 同じ商品の2回の追加を含め、合計が550円になる。
- 合計を繰り返し確認しても変わらない。
- 2つのCartがリストを共有しない。
